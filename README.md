# Studyflow prototype

A responsive, browser-based prototype for the AI Study Assistant described in the attached assignment.

## Open it

Open `index.html` in a current browser. It has no build step or external dependencies.

## What you can explore

- Dashboard with sample focus tasks, exam countdown, and subject progress
- Study plan view and a form to change the exam date, daily study time, and learning preference
- Tutor chat with sample replies for recursion, linked lists, quizzes, and recaps
- Three-question recursion quiz with feedback and progress updates
- Progress snapshot and reminder toggles

The content and learner profile are sample data. Tutor responses, reminders, and plan generation are local prototype behavior; connecting an AI model, saving accounts, importing a syllabus, and sending real notifications are next-stage app work.
